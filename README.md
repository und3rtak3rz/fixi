# Fixi

Веб-приложение для поиска СТО на карте, создания заявок на ремонт и получения предложений от подходящих мастерских.

План развития и вопросы для обсуждения: [roadmap](docs/roadmap.md).

Каталог автоуслуг: [исследование и UX-решения](docs/research/service-taxonomy-research.md), [полное дерево](docs/catalog/tree.md), [просмотр с поиском](docs/catalog/explorer.html), [JSON и CSV](docs/catalog/README.md).

Четыре варианта лендинга: [выбрать концепцию](landing-pages/index.html). Актуальное направление — [Pearl](landing-pages/04-pearl.html): белый дизайн, liquid glass и коралловые акценты. Описание и запуск: [лендинги](landing-pages/README.md).
