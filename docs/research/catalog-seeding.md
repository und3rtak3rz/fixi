# Fixi — автоматическое наполнение каталога Беларуси

Дата: 1 ноября 2026 года. Статус: продуктовое направление подтверждено пользователем; способ получения данных требует проработки.

## Цель

На старте карта содержит существующие автосервисы по всей Беларуси. Представитель находит свою карточку, подтверждает право управления, уточняет услуги и подключает отклики. Наполнение не зависит только от самостоятельной регистрации компаний.

Google Maps и Яндекс Карты — приоритетные источники для исследования возможностей получения данных. Скриншоты av.by используются как примеры услуг и смежных направлений; они не задают структуру, дизайн или необходимое количество компаний. Наблюдение пользователя о небольшом числе компаний на av.by не является независимой оценкой рынка.

## Порядок наполнения

1. Составить матрицу территорий Беларуси и направлений: ремонт, шиномонтаж, покраска, оклейка, детейлинг, мойки, электрика, EV, стёкла, эвакуация и остальные семейства справочника.
2. Проверить покрытие и ограничения источников, права на получение, сохранение, изменение и публикацию полей. Платный API сам по себе не означает право создать независимую копию каталога.
3. Провести пилот в крупном городе и небольшом населённом пункте; оценить стоимость, полноту обнаружения и качество совпадений до масштабирования.
4. Для разрешённых к хранению данных использовать промежуточные записи, нормализацию телефонов и адресов, сопоставление филиалов и очередь спорных совпадений. Хранение исходных ответов также зависит от условий источника.
5. Сопоставлять внешние рубрики с постоянными ID услуг Fixi. Сохранять происхождение и уверенность утверждений. Общая рубрика «автосервис» не означает наличие всех дочерних работ.
6. Автоматически публиковать записи, прошедшие правила качества; неоднозначные адреса, дубли и противоречия направлять на проверку. Показывать дату актуальности и статус «Представитель не подтверждён».
7. Предусмотреть «Это моя компания», исправление сведений, сообщение о закрытии и спор о принадлежности карточки. Следующий импорт не перезаписывает изменения подтверждённого владельца.
8. Обновлять данные повторными проходами с историей и постоянными идентификаторами. Отсутствие организации в одной выдаче не означает закрытие бизнеса.

Это план будущего импорта. Сбор данных и публикация компаний в рамках текущей работы не запускались.

## Проверка источников

**Google Places.** Официальная политика ограничивает предварительное получение, кеширование и хранение данных, кроме предусмотренных исключений; идентификатор места разрешено хранить бессрочно. При показе данных Places на карте требуется карта Google. Обычный Places API нельзя заранее считать разрешением на массовое постоянное наполнение собственной базы. [Политика Places API](https://developers.google.com/maps/documentation/places/web-service/policies).

**Яндекс.** Документация коммерческого API поиска организаций сообщает об отсутствии расширенной лицензии и запрете сохранения или изменения данных API. При этом на той же странице есть таблица с колонкой расширенной лицензии, а продуктовая страница описывает формирование клиентской базы. Эти противоречия нужно разрешить по применимому договору и письменному ответу поставщика именно для постоянного каталога Fixi в Беларуси. Покупку тарифа не считать достаточным подтверждением. [Документация API](https://yandex.ru/dev/commercial/doc/ru/concepts/geosearch), [продуктовая страница](https://yandex.ru/project/maps/api/search_rules/).

Если стандартные условия не подходят, проработать отдельное соглашение на данные и другие источники с подходящими правами: сведения от организаций, партнёрские выгрузки, сайты компаний и открытые наборы с проверкой их лицензий. Переход с API на извлечение HTML сам по себе не решает ограничения повторного использования.

## Статусы и качество

Наличие в каталоге, проверка актуальности контактов, подтверждение представителя, подтверждение услуги и готовность принимать заявки — самостоятельные признаки. Автоматический импорт не присваивает остальные статусы.

Отзывы, фотографии и рейтинги внешних площадок не переносятся автоматически вместе с контактами. Возможность использования каждого типа контента проверяется отдельно; собственная репутация Fixi хранится отдельно.

Готовность импорта: повторный проход не создаёт дубли; филиалы сети остаются разными точками; исправления владельца защищены; общие категории не превращаются в выдуманные компетенции; видны происхождение и актуальность данных. Отчёт показывает покрытие территорий и направлений, дубли, спорные записи, актуальность контактов и число подключившихся исполнителей. Число найденных записей не доказывает полного охвата всех компаний Беларуси.
