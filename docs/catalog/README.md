# Каталог автоуслуг Fixi

Исследовательское предложение от 1 ноября 2026 года. Основной каталог: 16 разделов, 509 услуг. Дополнительно: 20 услуг грузового расширения и 7 запросов с отложенным решением о публикации. Всего 536 записей и 828 поисковых синонимов.

- [Исследование, UX-решения и план проверки](../research/service-taxonomy-research.md).
- [Полное дерево](tree.md).
- [Интерактивный просмотр](explorer.html).
- [Все названия со скриншота и их сопоставление](screenshot-mapping.md).
- [JSON](services.json) — основной редактируемый источник.
- [CSV](services.csv) — экспорт для сверки и обсуждения.

Синонимы, связанные маршруты и варианты выполнения не считаются новыми услугами. Марки, модели, годы и параметры работы задаются отдельно. Применимость и компетенции нужно подтвердить у исполнителей; справочник не доказывает их наличие на рынке.

## Обновление

Редактировать `services.json`, интерфейс — `explorer.template.html`. Затем из корня репозитория:

```sh
python3 docs/catalog/render.py
```

Скрипт проверяет уникальность ID, единственного канонического родителя, названий, ссылки на услуги и источники; заново создаёт `tree.md`, `screenshot-mapping.md`, `services.csv` и `explorer.html`. Сгенерированные файлы отдельно не редактировать.

ID после публикации сохраняется при переименовании или переносе услуги. Не вычислять новые ID из актуального пути автоматически. При объединении услуг потребуются таблица перенаправлений и сохранение исторических связей заказов и подтверждений.

## Просмотр

`explorer.html` самодостаточен и открывается без сборки. Для локального сервера из корня репозитория:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть <http://127.0.0.1:4173/docs/catalog/explorer.html>.

Это инструмент проверки структуры, не готовый интерфейс каталога СТО. Поиск работает по подстрокам нормализованных слов и синонимам; опечатки и морфологический анализ не реализованы. Подсказки симптомов используют подготовленные сценарии и не являются AI-диагностикой.
