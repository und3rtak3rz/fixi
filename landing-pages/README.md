# Лендинги Fixi

Четыре направления дизайна для обсуждения. Откройте `index.html` в браузере — на нём есть предпросмотр и переход к каждому варианту. Актуальное направление — Pearl: белый фон, liquid glass, объёмные детали и коралловые акценты.

| Файл | Направление | Акцент |
| --- | --- | --- |
| `04-pearl.html` | Белый фон, стеклянные панели, скевоморфизм и коралловые акценты | Чистая подача, поиск СТО и тактильный интерфейс |
| `01-atlas.html` | Светлый фон, лаймовый цвет, спокойная подача | Карта, каталог, фильтры и подтверждения услуг |
| `02-garage.html` | Тёмный фон, янтарный цвет, крупная типографика | Симптомы, заявки и предложения мастерских |
| `03-drive.html` | Синий цвет, журнальная типографика | Подбор СТО, доверие и будущий AI-помощник |

## Просмотр

Можно открыть HTML-файлы напрямую. Сохраняйте папку `assets` рядом с ними: она содержит общие стили, демонстрационные взаимодействия и SVG-иллюстрации.

Для просмотра через локальный сервер из корня репозитория:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory landing-pages
```

Откройте <http://127.0.0.1:4173>.

## Что работает

- Адаптивная вёрстка, навигация по секциям и переход между концепциями.
- Фильтры каталога и связанные с ними точки схематичной карты.
- Поиск по марке, услуге и городу в Atlas, Drive и Pearl. Демоданные есть только для Минска; для остальных городов показывается пустое состояние.
- Выбор точки на карте и выделение соответствующей карточки СТО.
- Формы заявки, регистрации, подключения исполнителя и обращения в мастерскую с проверкой заполнения полей.
- Переключение подтверждений услуг в Atlas, Drive и Pearl.
- Пример уточняющего диалога AI в Drive.

Все данные СТО, оценки, счётчики и предложения демонстрационные. Формы не отправляют данные и не создают аккаунты или заказы. Загрузка документов и поиск по мануалам не подключены. Состояние взаимодействий действует до перезагрузки страницы.

HTML, CSS, JavaScript и иллюстрации находятся в репозитории. Внешних библиотек, шрифтов, картографических API и сборки нет.

В Pearl используется предоставленная пользователем фотография автомобиля: `assets/pearl-hero.jpg`. Снимок служит фоном первого экрана; затемнение и мобильное кадрирование задаются CSS. Контраст текста, размер подписей и тени усилены в обновлении от 24 октября 2026 года.
